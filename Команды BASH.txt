Команды BASH
pwd - нахождение
cd - перемещение
mkdir - создание
nano, vim - открыть текстовый файл
cat - просмотреть файл
mv - переименовать
cp - копировать файл
ssh keygen -t rsa - генерация ssh ключа (rsa - тип, -t - флаг)
cat .ssh/id_rsa.pub - вызов ssh ключа 
+git:
checkout - переместиться на другую ветку
branch -c  - создать ветку
add . - добавление файлов в индекс
clone - клонирование репозитория
status - статус файлов в репозитории
push origin HEAD - запушить в ветку, в которой находишься
pull: fetch - выгрузить файлы с репозитория + merge - слить вместе репозитории
